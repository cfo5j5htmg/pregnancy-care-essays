# 血常规如何排除白血病

> 更新时间：2026-09-15 (UTC+8)

血常规如何排除白血病更新时间:2022-08-24

血常规是白血病患者经常测试的基本血液测试，虽然早期白血病患者可能没有表现出血常规异常，但是我们很难从血常规单独判断一个人是否患有白血病。然而，血常规仍然是了解白血病状况的一个重要项目，接下来就让小编为大家简单介绍一下血常规如何排除白血病，希望对大家有所帮助。

1，血红蛋白和红细胞

从血常规表上的血红蛋白项目中，我们可以看出人体是否。正常人的血红蛋白男性为120 - 160克/升，女性为110 - 150克/升，新生儿的血红蛋白将更高，为170 - 200克/升。白血病患者的检查结果通常显示阳性细胞和色素性贫血。涂片观察后，年轻的红细胞有时会出现在血膜上，网织红细胞的数量经常减少，但少数病例可能略有增加。

2 ，血小板

血小板具有凝血功能。如果血小板很低，止血功能就会很弱。血小板在一定程度上很低，可能大量出血。白血病早期的血小板数量可以正常减少或轻微减少，而在中晚期，血小板数量会显著减少，低于10×109 / L，有不同大小的血小板、畸形、巨大的血小板、血小板凝血功能异常。

3，白细胞

白细胞是是否有炎症的指标，白细胞高达300×109 / L，或者低至( 0.2 ~ 0.3 )×109 / L。急性白血病的白细胞数量在初期通常较低，在后期较高。如果白细胞数量在很大范围内处于高侧和低侧，特别低或特别高，这将表明白血病的情况已经非常严重，此时的治疗很难取得效果。外周血中急性白血病细胞的存在是诊断急性白血病的重要依据。当白细胞总数高时，诊断并不难，但是当白细胞低时，白血病细胞通常只能通过浓缩涂片的尾部或血液涂片来发现。

综上所述就是关于血常规如何排除白血病的详细介绍，希望对大家有所帮助，仅从血常规来看，如果所有指标显示正常，很难排除白血病的可能性。因此，为了避免白血病的误诊或漏诊，如果患者觉得他们有可能患上白血病，他们应该根据医生的建议做进一步的诊断检查，比如骨骼检查，以更准确地了解该疾病。
